# 指数前瞻估值与回报

2026-10-24用户确认的方法补充。与[七项条件](screening.md)、[成本与执行](costs-and-execution.md)并行使用，不改变任何筛选门槛、投资原则或现行交易/监控设置。关键输入与更新记录按[估值证据与变更记录](valuation-evidence.md)处理。

## 选择适用的价值依据

| 指数特征 | 主要研究依据及限制 |
|---|---|
| 盈利基础可解释的宽基 | 行业结构、正常化盈利、资本回报、分红与再投资；PE结合利润周期，不能只看历史低分位 |
| 红利或现金流策略 | 普通分红/现金流的持续性、派息与再投资、行业集中和调样规则；高股息可能来自股价下跌或盈利下降，现金流不必然分给股东 |
| 科技、亏损股占比较高 | 盈利覆盖、亏损处理、主要行业及权重公司的商业化与融资摊薄；必要时分组建模，缺少依据时保留条件情景，不强用总PE |
| 金融权重较高 | PB结合可持续ROE、资本约束和资产质量；不同金融业务不强套工业企业现金流指标 |
| 黄金等非企业盈利资产 | 不适用PE、企业盈利增长或股息模型；保留资产特征、风险与配置分析，不为统一格式制造盈利估值 |

指数PE须说明汇总方法、亏损股和极端值处理；PB及股息率也须保留计算口径。不能随意把成分股PE加权平均当作指数PE。历史分位记录窗口、发布前回溯、规则版本及行业权重变化；旧样本结构下的低倍数不构成永久价值下限。

## 从基本面到条件回报

对适用盈利模型的指数，按以下因果关系选取少量关键输入：

当前可核验的正常化盈利基础 → 行业盈利与资本回报支持的增长 → 分红及必要再投资 → 持有期末合理估值 → 对应持有期回报。

- 保留增长、派息、再投资与资本回报之间的约束。不能同时假设高增长、高派息和无需新增投入而无解释；融资摊薄应反映到每份经济权益。指数调样、成分公司增发及权重变化不是无成本增益。
- 谨慎、基准和积极情景各给经营依据及主要反证；下行情景允许盈利下降与估值压缩同时发生。不得仅把输入统一上下浮动10%当作完成预测，也不编造情景概率。
- 期末倍数由增长、质量、资本需求及风险解释，历史和同类倍数只作交叉检验。持有期、期末估值、回报要求均为当次明示假设，不新增永久固定门槛。

适用时，用同一可比单位说明计算：P0为当前价格，E0为对应盈利基础；在明确的简化假设下，ET=E0×(1+g)^T，PT=ET×期末PE。指数点位、盈利和估值口径必须一致；若用P0/当前PE反推E0，标为计算并继承PE源数据局限。指数调样和汇总口径无法衔接时，不强套这组公式。

若分红Dt不再投资且不计现金利息，持有期总回报=(PT+ΣDt)/P0−1；(1+总回报)^(1/T)−1是期末财富的年化表达，不是考虑各期分红时间的资金加权收益率。要计分红再投资，需明确再投资路径；要计算资金加权回报，需列实际时点现金流，不能混称。

给定有依据的回报要求r，可以用P*=Σ[Dt/(1+r)^t]+PT/(1+r)^T形成条件性可支付价格。它依赖上述输入而非客观精确价值，须同时展示下行情景和敏感性；风险已在现金流或r体现时，不再无解释地重复折价。反推现价要求的增长或期末倍数，并与基本面证据比较，不能只依赖估值扩张提供回报。

PE倒数是盈利收益率，不是预期回报；不可将其与股息率直接相加。若采用全收益指数或分红再投资序列，不再加一次股息。成长依赖再投资，不能既把全部盈利作为现金分配又保留全部增长。

## 从指数到基金和成交价格

- 先得到指数层面的情景，再用同币种、分红与税务口径相匹配的产品成本转换为基金层面的条件回报。采用实际跟踪差作为综合参考时，不再扣已包含的管理费、托管费等；跟踪误差不能当作每年的收益损失。
- 历史跟踪差不保证未来，跨市场基金另处理汇率、税务及交易时差。成交佣金、价差及折溢价变化属于执行层，按成本参考核算，不能把低溢价称为指数低估。
- 指数点位区间映射到ETF净值或份额价格，必须有同日锚点并处理分红、份额折算、汇率及跟踪差；映射不充分时只报指数情景，不报精确ETF买入价。

## 报告与复核的最小内容

1. 七项资格、指数价值、产品与交易质量、组合适配分别给结论，不以其中一项抵消另一项。
2. 估值卡列日期与口径、适用模型、关键输入及依据、条件回报/价值区间、现价隐含要求、敏感性、缺口影响及失效条件；证据不足时可以只给条件模型。
3. 更新按“原依据与区间 → 新证据或纠错 → 假设前后值 → 新区间与差异 → 结论影响”记录，无法量化时标明原因，不伪造单项贡献。价格变化单独更新吸引力，不自动改变价值。
4. 现金、持仓和底层重叠不足限制个性化金额建议，不自动阻断指数研究；历史估值分位缺失不阻止有依据的前瞻分析。筛选排名缺失则仍不得宣称七项全过。

新财报、指数规则/结构实质变化、分红或其他使口径改变的事件触发相关输入复核。方法更新或研究判断不自动修改既有订单、价格阈值、持仓和监控；原有规则不因新增模型而豁免。
