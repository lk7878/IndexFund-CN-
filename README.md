# IndexFund-CN 指数助手

用于 ETF 与指数基金筛选、指数价值分析、费用和跟踪比较、折溢价核验及条件交易计划的 Codex skill。

## 使用

将本仓库的 `indexfund-cn` 文件夹复制到本机技能目录（例如 `~/.codex/skills/indexfund-cn`），并在客户端重新加载技能后调用：

```text
请用 $indexfund-cn 按我的筛选条件复核ETF，注明行情与净值日期，比较指数估值、费用、跟踪和折溢价。
```

请提供当前投资预算、持仓、期限和风险承受能力。未核实的数据会标为待核实；历史推荐不代表当前入选。

## 文件

- [技能入口](indexfund-cn/SKILL.md)：七项筛选要求、工作顺序与输出边界。
- [筛选口径](indexfund-cn/references/screening.md)：同类排名、三年统计、经理回报和费用优势。
- [成本与交易](indexfund-cn/references/costs-and-execution.md)：总成本、跨市场时差、折溢价、流动性与配置。
- [来源与适用边界](indexfund-cn/references/context.md)：规则来源与不应默认继承的历史参数。
- [界面元数据](indexfund-cn/agents/openai.yaml)：显示名称与调用提示。

## 适用范围

本技能按使用者确认的七项条件进行研究。某次分析对排名或经理回报的临时放宽，不会自动修改长期规则。实时搜索优先使用 AnySearch；本仓库不附带该技能、服务凭据或行情订阅，需在使用环境另行配置，并遵守技能中的回退约定。

技能不连接券商下单，不将计划视为成交，也不会因安装而自动开启监控。需要实时行情时必须重新获取并核对数据时点。
